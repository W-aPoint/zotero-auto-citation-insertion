# Zotero 扫描标记引文

把 Scannable Cite 纯文本标记放进对应句子，在对话中返回可粘贴的正文。Word 和 Zotero 的操作均由用户亲自执行。本技能交付的是待扫描的文本标记。

按之前的格式补充引文时，见同级的 [在正文中排入 Zotero 引文标记](../zotero-word-workflow/SKILL.md)。仅使用用户提供的文字、真实标记或映射。收到路径或分类名只用于定位。

## 确认输入与身份

根据用户给出的正文和文献映射定位引文。沿用原句、引用顺序和现有标点，将缺失的映射列在正文外。

优先使用用户已有的 Scannable Cite 导出、条目 URI 或验证过的文献映射。助手不为配键连接 Zotero。身份必须能追溯到实际文献及 Zotero 文库。DOI、PMID、数字引文序号、数据库 itemID 和本机 libraryID 都不能直接充当标记中的条目标识。账号、文库和条目键必须由实际来源取得，不复用旧论文或示例中的值。不直接写 Zotero SQLite 数据库，不为读写失败擅自改变通信权限。

准备标记前阅读 [语法与转换说明](references/workflow.md)。该说明包含五字段语法、个人库/群组库、多篇合引、页码，以及内置 RTF Scan 与本插件的区别。优先沿用 Scannable Cite，不自动切换成 Pandoc 或作者年份 RTF 标记。

## 写作和既有数字引文转换

- 新写作：在已确定引用对象的位置插入标记。多篇合引直接连接多个标记，不用分号或额外文字隔开。前后缀、页码写进相应字段。
- 旧稿：先建立“数字序号 → 文献 → 真实 Zotero 标识”的完整对应关系，再转换明确属于引文的数字串；展开 `[3–5]` 等范围逐条匹配。不要把公式、数组、统计区间或参考文献条目编号一并替换。缺失或歧义映射按具体位置列出，不猜配。

## 供用户手动处理旧稿时参考

以下文档处理、插件及 Word 检查步骤仅用于回答用户的操作问题。助手生成标记时不运行这些步骤。

- Word 引文可能横跨多个 `w:r/w:t`。先在段落级识别文字与位置，再仅修改目标范围；保留邻近文本运行、段落属性、超链接、书签、图形和表格，不能用整段 `.text = ...` 重建带格式段落。正文、表格、脚注和尾注均需盘点；页眉、页脚和文本框有标记时单列核实插件支持。
- 已存在的 Zotero 活动引文默认不转换成标记或纯文本。新旧混合稿先在独立小样验证扫描能保留原活动字段。反向转换只在用户明确要求时进行。
- 原有手工参考文献列表默认保留在备份/阅读稿。若要让 Zotero 重建列表，仅在扫描副本中移除已确认的手工条目，保留标题；不得删除包含说明、图表或其他内容的整个文后区域。

修改前后比较原稿哈希、正文非引文文字、表格/图片及已有活动引文身份；只有用户授权的文字增补、排版或参考文献区处理可列为差异。需要交付 DOCX 时遵循当前可用的文档技能进行渲染检查；标记较长造成的临时撑行不等于最终活动引文排版。

## 用户手动核验扫描稿

使用本技能的只读核验脚本，映射表见参考说明：

```text
python scripts/validate_scan_docx.py manuscript_scan.docx --mapping reference_map.json --report scan_qa.json
```

脚本按段落拼接文本运行，统计正文、表格和其他文档部件中的标记，检查五字段语法、标识和映射一致性，报告现有活动引文。输入文件只读，报告不得覆盖输入或映射表。脚本只验证“与所提供映射一致”，不证明条目在当前 Zotero 库中真实存在，也不证明扫描/Word 刷新成功。

阅读用户提供的核验结果时，区分 **引文组数、条目引用次数、唯一文献数**；唯一文献以完整文库及条目标识去重，不能仅按作者年份或条目键去重。

## 用户手动转换与核对

用户询问如何扫描或生成文献表时，再提供以下手工步骤。

1. 确认安装的是支持所需文件类型的 ODF/DOCX Scan 插件，以及 Word 的 Zotero 插件。检查实际版本和菜单；旧版只支持 ODT 时不得宣称可以直接扫描 DOCX。
2. 在 Zotero 的扫描工具选择 **Markers → Zotero citations**，指定输入和独立输出。菜单名称可能仍为 **ODF Scan**。
3. 在 Word 打开转换文件，使用 **Document Preferences** 选择用户需要的 CSL 样式，执行 **Refresh**，已有活动书目时查看更新结果。需要新增书目时，将光标放在所需位置并点击 **Add/Edit Bibliography**。
4. 核对未解析标记、引文组及条目身份、唯一文献数和参考文献对应关系，确认旧活动引文保留；用 **Add/Edit Citation** 抽查正文和表格中能编辑的真实条目、合引和定位信息。重新检查分页。

用户分享手动操作的结果时，可区分标记准备、扫描转换和书目刷新各自的状态。仅交付标记时，说明文字已备好、待用户扫描。表格及页面数量、参考文献总数不能硬编码成既往文章的数字。

维护核验脚本时运行 `python scripts/test_validate_scan_docx.py`，再运行 skill-creator 的 `quick_validate.py` 验证技能结构。
