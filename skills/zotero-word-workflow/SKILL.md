# 在正文中排入 Zotero 引文标记

收到“插入文献”或“按之前的格式引用”时，直接返回带标记的原句或段落，由用户复制到稿件。稿件路径、文库分类名和光标位置仅供定位。导入与归档、修改原稿、运行扫描、刷新或生成书目都由用户亲自执行。本技能只处理文本，不启动 Word、不连接 Zotero，也不调用文档或文库自动化脚本。

1. 确认每篇文献支持的具体表述，保留原句措辞、语言、标点和已有引文。把对应标记放在所支持的句子或分句旁，沿用稿件的引文位置习惯。
2. 优先原样使用用户给出的 Scannable Cite 标记。也可根据用户提供的、已核实的 Zotero 条目 URI 或文献与条目键映射填写。只有题名、DOI、PMID 或参考文献序号时，指出哪一篇缺少真实标记或完整条目身份。先返回其余已经配好的文字，待补项单列在正文外。
3. 每条标记依次含前缀、可读作者年份、定位信息、后缀、完整条目标识。四条竖线和两端花括号均为半角，空字段保留。个人库用 `zu:用户ID:条目键`，群组库用 `zg:群组ID:条目键`。同处合引按原顺序紧邻排成 `}{`。页码写在第三字段，保留已给出的前后缀和抑制作者设置。

以下仅示意格式，尖括号内的文字在实际交付中须换成已核实的信息。

```text
{ | <作者>, (<年份>) | | |zu:<用户ID>:<条目键>}
{ | <作者甲>, (<年份>) |p. 45 | |zg:<群组ID>:<条目键甲>}{ | <作者乙>, (<年份>) | | |zg:<群组ID>:<条目键乙>}
```

默认在对话中交付标好引文的正文。只有用户询问如何操作时，再说明手工步骤。用户扫描后，需要新建参考文献表时，自行将光标放到目标位置并点 **Add/Edit Bibliography**。已有活动书目需要更新时，由用户点 **Refresh**。
